# Trend Playlist for Home Assistant

Experimental **preview-only** Home Assistant OS app and custom integration for the TIDAL playlist workflow. No publishing action is provided.

**[Installation and testing guide](INSTALL.md)**

## Installation repository URL

`https://github.com/Wakizashimaster/trend-playlist-ha`

The Home Assistant app is packaged in `trend_playlist_preview/` and the HACS custom integration in `custom_components/trend_playlist/`. The app bundles the Python preview code; it does not clone the private development repository.

**Never commit TIDAL session files, Gmail credentials, playlist snapshots, or personal configuration.**

This is an untested initial package. Validate installation and preview execution before depending on its weekly schedule. The existing Windows workflow remains the fallback.
